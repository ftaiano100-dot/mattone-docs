<Warning>
**Questa area è interna al team e NON viene pubblicata su `docs.mattone.co`.**
Vive nella cartella `internal/` del repo `mattone-docs` (versionata, per il team) ma è esclusa dal build Mintlify tramite `.mintignore`. Non è referenziata nel menu (`docs.json`). Contiene know-how tecnico e casistiche PMS secondarie — riferimento per chi costruisce, non materiale per gli studenti.
</Warning>

<Warning>
**Fuori dal sito sì, fuori da GitHub no.** `.mintignore` esclude `internal/` dal build Mintlify, quindi queste pagine **non sono mai state online**. Ma `mattone-docs` è un repo **pubblico**: chiunque può leggerle su GitHub. Mintlify non supporta i repo privati sul piano in uso (verificato 27/08/2026), quindi la situazione resta questa.

Conseguenza operativa, per chi scrive qui: **mai credenziali.** Token, password, API key, PIN, secret vanno nel Vault o in `.env`. Nomi di clienti e architettura ci sono già ed è una scelta consapevole; i segreti no, mai.
</Warning>

## Schede per studente

[**Studenti**](/internal/studenti) — una pagina per workspace: PMS, canali, cosa è rotto, cosa è stato fatto e quando. Si parte da lì quando un cliente segnala qualcosa.

## Perché esiste

Alcune cose non stanno bene nella guida pubblica: integrazioni marginali (PMS di nicchia), dettagli di reverse engineering, pattern architetturali interni, "come facciamo le cose" lato Conduit. Le teniamo qui: **nel repo sì, sul sito no.**

## Come è tenuta fuori dal sito

Meccanismo: la cartella `internal/` è elencata in **`.mintignore`** (l'equivalente di `.gitignore` per il build Mintlify). Le pagine **non in `docs.json` sarebbero comunque raggiungibili via URL diretto** sul sito pubblicato; `.mintignore` invece le **esclude del tutto dal build**, quindi non finiscono online in nessuna forma. Restano versionate in git per il team.
