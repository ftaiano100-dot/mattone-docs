ImmobiNet (motore tecnico **Rentallab**) è un PMS italiano usato da alcuni property manager, tipicamente ex-agenzie immobiliari con volumi alti (es. lo studente Mattone con ~190 appartamenti a Jesolo). A differenza di KrossBooking o Hostaway, ImmobiNet **non espone API REST moderne**: parla solo **SOAP/XML**, una tecnologia più vecchia. Per questo non si collega "out of the box" con Conduit, PriceLabs e gli altri strumenti che consumano REST. Questa sezione raccoglie tutto quello che sappiamo e definisce i path ufficiali per integrarlo.

## Perché ImmobiNet è "diverso e antiquato"

| Aspetto | PMS moderno (Kross, Hostaway) | ImmobiNet / Rentallab |
|---|---|---|
| Protocollo | REST/JSON | **SOAP 1.1 / XML** (document/literal) |
| Auth | API key / Bearer token | **username + password in chiaro nel body** (no token, no OAuth, no WSSE) |
| Documentazione | Portale partner / doc pubblica | **Nessuna doc ufficiale** — tutto reverse-engineered dal WSDL |
| Sync nativo Conduit | Sì (import source) | **No** — serve un bridge + custom tools |
| Sync nativo PriceLabs | Sì | **No** — non è in lista integrazioni PriceLabs |
| Prezzi | euro decimali | **centesimi** (`int`, euro × 100) |
| Disponibilità | JSON strutturato | **stringa binaria** `0`/`1` giornaliera |

Il WSDL pubblico è `https://rentallab.immobinet.it/webservice.wsdl` ed è un **aggregatore di 5 bundle** SOAP (agenzia, gruppi, listini/regole, offerte, pulizie). L'analisi completa (17 operazioni) è in [SOAP Webservice](/internal/immobinet/soap-webservice).

## Verdetto per integrazione

| Integrazione | Verdetto | Path ufficiale |
|---|---|---|
| **Conduit AI (AI Ospiti)** | ✅ Fattibile | **Custom Tools Conduit** che chiamano un bridge di estrazione on-demand. Path confermato da Raniel (Conduit). Vedi [Conduit via Custom Tools](/internal/immobinet/conduit-custom-tools) |
| **Direct Booking Site** | ✅ Fattibile al 100% | Tutti i metodi read + write prenotazioni esistono. Pattern `cosmica-booking` + adapter ImmobiNet |
| **PriceLabs (revenue)** | ⚠️ Solo indiretto | Nessun write su prezzi via SOAP. Soluzione **Hybrid Sync**: iCal in lettura + Direct Connect alle OTA in scrittura. Vedi [PriceLabs Hybrid Sync](/internal/immobinet/pricelabs-hybrid-sync) |

<Warning>
**Il collo di bottiglia è l'ESTRAZIONE dei dati da ImmobiNet, non l'integrazione a valle.** Il bridge (`immobinet-bridge`) ha già l'invio delle richieste SOAP e l'auth verificati, ma il **parser delle risposte è ancora uno stub**: si completa solo quando arrivano le **credenziali reali del cliente** (Alberto Milan / Rentallab) per vedere la forma effettiva dell'XML. Finché mancano quelle credenziali, nessun path va live. Vedi [Stato del bridge](/internal/immobinet/bridge-stato).
</Warning>

## Come si incastrano i pezzi

```
                 ImmobiNet (SOAP/XML, rentallab.immobinet.it)
                        │
        ┌───────────────┼────────────────────────┐
        │ estrazione    │ iCal (read)            │
        ▼               ▼                         ▼
  immobinet-bridge  PriceLabs Hybrid Sync   Direct Booking Site
  (SOAP→REST)       (write prezzi → OTA)    (setPrenotazione + Stripe)
        │
        ▼ endpoint HTTP (get_reservations / get_guest / get_checkin)
  Custom Tools Conduit (registrati da DASHBOARD, non via MCP/API)
        │
        ▼
  AI Ospiti interroga on-demand
```

I tre lavori (Conduit, Direct Booking, PriceLabs) sono **paralleli e indipendenti**: si possono avviare separatamente, tutti condividono lo stesso layer di estrazione SOAP.

- **WSDL ImmobiNet/Rentallab**: `https://rentallab.immobinet.it/webservice.wsdl` (nessuna doc ufficiale, tutto reverse-engineered il 2026-04-23; probe live endpoint 2026-05-11).
