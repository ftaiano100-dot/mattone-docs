## Cos'è
Serratura smart **SwitchBot** (Lock / Lock Pro). L'ospite apre da un link; Conduit può aprirla via MCP. Richiede un **Hub Mini** in loco per il controllo da cloud.

## Prerequisiti (fondamentali)
- **Hub Mini** alimentato, su WiFi **2.4GHz**, LED **blu fisso**.
- Serratura **entro ~5 m** dall'Hub, senza muri spessi/metallo/TV.
- Token+Secret dall'account **owner** della Home (causa #1 dei problemi).
- **"Cloud Service" attivo** sulla serratura.

## Step di collegamento (in ordine)
<Steps>
  <Step title="Genera Token + Secret">App SwitchBot → Profilo → Preferenze → tap 10× sulla versione → Developer Options → **Generate**. ⚠️ dall'account **proprietario** dell'Hub.</Step>
  <Step title="Prendi il Device ID">App → serratura → ⚙️ → Device Info → copia il Device ID.</Step>
  <Step title="Registra il device">Entry nel registro del tool (slug, deviceId, deviceType, propertyName) + env `SWITCHBOT_TOKEN`/`SWITCHBOT_SECRET`.</Step>
  <Step title="Testa e leggi i log">Apri dal link. Se fallisce, leggi `rawStatus` → [Troubleshooting SwitchBot](/troubleshooting/switchbot).</Step>
</Steps>

## Come funziona (comandi)
- Base: `https://api.switch-bot.com/v1.1`, firma HMAC-SHA256 (token, sign, nonce, t).
- Sblocco: `POST /devices/{id}/commands` → `{commandType:"command", command:"unlock", parameter:"default"}`.
- Stato: `GET /devices/{id}/status`.
