## Sintomo → Causa → Soluzione
| Sintomo | Causa probabile | Come si risolve |
|---|---|---|
| Test connessione rosso | terna errata / password API scaduta | rigenera dal portale Kross, ri-salva |
| Risposte "occupato" quando è libero | tool nativo flaky / manca skill | usa `check-availability` + skill prompting |
| 429 troppe richieste | fan-out lookup | cache+coalesce (gateway); non ripetere fan-out |
