Questo catalogo elenca tutti i custom tool Conduit provisioned dal team Mattone e il loro stato attuale. Consulta questa pagina prima di ogni onboarding per verificare quali tool sono disponibili per lo studente che stai attivando, un tool non attivo non può essere assegnato.

## Tool Kross

Questi tool interrogano il PMS KrossBooking per dati di prenotazione, check-in e disponibilità.

| Tool | Descrizione | Stato |
|---|---|---|
| `check-availability` | Verifica disponibilità appartamento per date | Attivo |
| `check-portal-status` | Stato check-in online dell'ospite | Attivo |
| `get-reservation-status` | Dettaglio prenotazione corrente | Attivo |
| `get-checkin-instructions` | Istruzioni accesso per listing | Attivo |
| `get-in-house-guests` | Ospiti attualmente in casa | Attivo |
| `get-incomplete-portals` | Portali check-in non completati | Attivo |

## Tool Smart Lock

Questi tool controllano i dispositivi fisici di accesso (Shelly, SwitchBot) e generano link per gli ospiti.

| Tool | Descrizione | Stato |
|---|---|---|
| `open-door` | Apertura porta/citofono remota | Attivo |
| `check-device-status` | Stato device (online/offline/batteria) | Attivo |
| `get-access-link` | Genera link di apertura per l'ospite | Attivo |

## Tool Stripe

Questi tool gestiscono la generazione di link di pagamento per extra e upsell.

| Tool | Descrizione | Stato |
|---|---|---|
| `stripe-payment-link` | Genera link pagamento per extra/upsell | Attivo |

## Regola fondamentale

<Warning>
  Ogni tool va **sempre** abbinato alla sua skill di prompting corrispondente. Senza la skill, l'agente Conduit ignora il tool anche se è attivo, il tool da solo non basta. Verifica sempre la coppia tool + skill prima di completare un onboarding.
</Warning>

<Note>
  Se noti una discrepanza tra questa pagina e il comportamento effettivo di un tool, segnalalo al team tecnico indicando il nome del tool e il sintomo osservato, provvederemo ad aggiornare sia il catalogo che la configurazione.
</Note>

<Note>
  Questa pagina elenca i **custom tool Conduit** (quelli che usa l'agente). Per gli **strumenti che usa il team** per comunicare con gli studenti da Claude Code, **WhatsApp MCP**, **Slack MCP**, **Resend**, e come collegarli alla tua sessione, vedi [Strumenti del team per comunicare con gli studenti](/riferimenti/strumenti-team-studenti).
</Note>
