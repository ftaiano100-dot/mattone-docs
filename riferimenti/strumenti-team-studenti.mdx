Per fare delivery a volumi il team **comunica con gli studenti direttamente da Claude Code**: manda e legge messaggi WhatsApp, usa i canali Slack, e invia email. Non tutti nel team hanno già collegato questi strumenti alla propria sessione: questa pagina spiega **cosa fa ciascuno** e **come installarlo**, e chiude con la best practice per **avvisare lo studente di cosa gli manca**.

<Warning>Regola zero-segreti: nessun token, numero di telefono o valore reale in questi docs, nei repo o in chat. Le credenziali dei connettori vivono nel gestore accessi del team / Vault. Se un segreto viene esposto, **ruotalo subito** (vedi [Credenziali](/riferimenti/credenziali)).</Warning>

## Gli strumenti in breve

| Strumento | Cosa fa | Come si usa |
|---|---|---|
| **WhatsApp MCP** | Mandare e leggere messaggi WhatsApp **agli studenti** da dentro Claude Code. | MCP collegato alla tua sessione Claude Code. |
| **Slack MCP** | Leggere/scrivere nei **canali team e studenti** su Slack (annunci, FYI, notifiche pulizie). | MCP collegato alla tua sessione Claude Code. |
| **Resend** | Mandare **email** (transazionali/reminder). Già usato **dalla piattaforma** per reminder e recupero password. | Servizio email via API della piattaforma; opzionalmente come MCP per inviare email da Claude Code. |

<Note>WhatsApp e Slack sono canali **diretti verso lo studente/team**; Resend è il motore email. Scegli il canale in base al pezzo mancante e a come di solito quello studente risponde (molti rispondono più in fretta su WhatsApp).</Note>

## Come si aggiunge un MCP a Claude Code (flusso generico)

Questo è il flusso **ufficiale** di Claude Code per aggiungere un server MCP, valido per qualsiasi MCP (inclusi WhatsApp e Slack). I comandi sotto sono la sintassi ufficiale della CLI.

<Steps>
  <Step title="Aggiungi il server MCP">
    A seconda di come è distribuito il server, usi una di queste forme:

    ```bash
    # Server remoto HTTP
    claude mcp add --transport http <nome> <url>

    # Server remoto SSE
    claude mcp add --transport sse <nome> <url>

    # Server locale (stdio): il comando che avvia il server va dopo "--"
    claude mcp add <nome> -- <comando> [argomenti...]
    ```

    Flag utili:
    - `--scope local|project|user`, dove salvare la config. Default `local` (solo per te, in questo progetto). `user` = disponibile in tutti i tuoi progetti. `project` = condiviso col team via file `.mcp.json` nel repo.
    - `-e CHIAVE=valore` (o `--env CHIAVE=valore`), passa una variabile d'ambiente/segreto al server (es. una API key). **Non incollare mai il valore reale nei docs o in chat.**
  </Step>
  <Step title="Verifica che sia collegato">
    ```bash
    claude mcp list          # elenca i server e il loro stato
    claude mcp get <nome>    # dettagli di un singolo server
    ```
    Dentro una sessione Claude Code puoi anche aprire il pannello con `/mcp`. Per rimuoverne uno: `claude mcp remove <nome>`.
  </Step>
  <Step title="Usa lo strumento dalla sessione">
    Una volta collegato, i tool dell'MCP diventano disponibili a Claude Code: puoi chiedergli di mandare un messaggio WhatsApp/Slack o un'email allo studente. Se un MCP **non** risulta collegato, il primo passo è aggiungerlo con il comando qui sopra.
  </Step>
</Steps>

<Info>
  **Fonte ufficiale (verificata).** La guida MCP di Claude Code è su [code.claude.com/docs/en/mcp](https://code.claude.com/docs/en/mcp) (quickstart: [code.claude.com/docs/en/mcp-quickstart](https://code.claude.com/docs/en/mcp-quickstart)). La sintassi `claude mcp add / list / get / remove` e i flag `--transport`, `--scope`, `-e` qui sopra sono presi da lì.
</Info>

## Collegare i singoli strumenti

<Warning>
  **Non abbiamo pubblicato qui l'endpoint/comando esatto di ogni MCP per non inventare URL.** Per WhatsApp MCP e Slack MCP usa **l'URL o il comando di installazione ufficiale fornito dal team** (gestore accessi / canale interno): incollalo nel comando `claude mcp add` del flusso generico qui sopra. **Il link/comando specifico va confermato prima di pubblicarlo**, meglio chiederlo al team che affidarsi a un indirizzo non verificato.
</Warning>

### WhatsApp MCP
- **Cosa fa:** manda e legge messaggi WhatsApp con lo studente da Claude Code (avvisi su cosa manca, follow-up, conferme).
- **Come si collega:** aggiungilo con `claude mcp add` (flusso generico sopra), usando l'endpoint/comando ufficiale del team. Alcuni server WhatsApp richiedono un primo abbinamento del numero/account: segui le istruzioni del team.
- **Da confermare col team:** l'endpoint/pacchetto esatto e l'eventuale procedura di pairing. *(non inventare l'URL)*

### Slack MCP
- **Cosa fa:** legge e scrive nei canali Slack del team/studenti (es. notifiche pulizie via `SEND_SLACK_MESSAGE` lato Conduit, FYI operativi, annunci).
- **Come si collega:** `claude mcp add` con l'URL/comando ufficiale del workspace Slack fornito dal team, più l'autorizzazione all'app Slack.
- **Da confermare col team:** l'endpoint/app Slack esatta e gli scope. *(non inventare l'URL)*

### Resend (email)
- **Cosa fa:** invia email. È **già integrato nella piattaforma** Mattone per reminder e recupero password (via API, lato server).
- **Come si usa:** per le email di sistema non serve fare nulla, le manda la piattaforma. Per inviare email **da Claude Code** esiste l'opzione di un MCP Resend che usa una API key Resend passata come env (`-e`), **mai** in chiaro nei docs.
- **Da confermare col team:** se e quale MCP Resend usare e dove sta la API key (Vault / env). *(non inventare pacchetto o URL)*

## Se non hai ancora collegato uno strumento

Se `claude mcp list` non mostra WhatsApp o Slack, non ce l'hai ancora nella tua sessione: **aggiungilo** con il flusso generico qui sopra (`claude mcp add …`) usando l'endpoint ufficiale del team, poi verifica con `claude mcp list`. Finché non è collegato, puoi comunque farti preparare il **testo** del messaggio da Claude e inviarlo a mano dal tuo WhatsApp/Slack.

## Best practice: avvisare lo studente di cosa gli manca

Quando dallo stato dell'onboarding risulta che manca un pezzo **dello studente**, la carta / il pagamento, il collegamento Notion, il contratto firmato, la Restricted Key Stripe, il numero per WABA, **avvisalo subito**, con un messaggio plain, gentile e chiaro. Ricostruisci "cosa manca" incrociando le tre fonti in [Stato & continuazione](/onboarding/stato-e-continuazione) (`/connessioni` + `pms_integrations` + Vault).

Principi del messaggio:
- **Un elenco corto**: solo i pezzi mancanti, non tutto l'onboarding.
- **Per ogni pezzo, l'azione concreta** e dove farla (link alla piattaforma quando c'è).
- **Tono gentile e diretto**, niente gergo tecnico né ID/endpoint (quelli restano tra noi).
- **Chiedi conferma quando è fatto**, così aggiorni lo stato.

<Note>
  **Esempio di messaggio (WhatsApp / Slack / email), plain:**

  > Ciao [Nome]! Per completare l'attivazione del tuo assistente ci mancano un paio di cose da parte tua:
  >
  > 1. **Collegamento Notion**, vai su app.mattone.co → Connessioni → *Collega Notion* e autorizza (è un click, non devi incollare nessuna password).
  > 2. **Contratto firmato**, trovi il contratto nella tua area: una volta firmato ci sblocca l'attivazione.
  > 3. **Metodo di pagamento**, aggiungi la carta così possiamo far partire il servizio.
  >
  > Appena fatte, scrivimi un "ok" qui e proseguo io con il resto. Grazie!

  Adatta l'elenco ai pezzi realmente mancanti per quello studente. Per la Stripe scriveresti p.es. *"crea una chiave a permessi limitati e incollala in Connessioni → Pagamenti"* (guida + video: [Pagamenti Stripe](/onboarding/5-pagamenti-stripe)); per il numero WhatsApp/WABA vedi il box "Cosa dire allo studente" in [Telefonia e WABA](/integrazioni/conduit/telefonia-waba).
</Note>

<Tip>
  Prompt pronto per generare e (dopo tua conferma) inviare questo avviso: sezione **"Avvisare lo studente di cosa gli manca"** in [Prompt per Claude Code](/riferimenti/prompt-claude-code). Fai **sempre** rivedere la bozza e conferma canale + destinatario prima dell'invio.
</Tip>
