---
title: "Glossario"
description: "I termini che ricorrono in questi docs, spiegati semplici."
---


| Termine | Cosa vuol dire |
|---|---|
| **PMS** | Il gestionale prenotazioni (studenti: **KrossBooking**; Dubai: Hostaway). |
| **Conduit** | L'assistente AI che risponde agli ospiti. Un "cervello" per studente (workspace). |
| **Workspace** | Lo spazio Conduit di UNO studente: KB, agente, tool. |
| **KB** | I documenti che l'AI legge per rispondere. **Per-appartamento**, mai globale. |
| **listing_id** | L'ID di un singolo appartamento (lega la KB al posto giusto, anti-leak). |
| **Custom tool** | Un'azione che l'AI può fare (aprire porta, link pagamento, disponibilità). |
| **Skill** | Le istruzioni su *quando/come* usare un tool. Senza, il tool è ignorato. |
| **Guardrail** | Regola "non fare mai X" imposta all'agente. |
| **Hub Mini** | La scatoletta SwitchBot che collega la serratura al cloud/WiFi. |
| **WABA** | WhatsApp Business Account — il numero ufficiale dell'agente. |
| **MCP** | Il ponte con cui Conduit chiama i nostri tool. |
| **Gateway** | `mcp.mattone.co` — smista le chiamate studenti verso Kross/Shelly/Stripe. |
| **Vault** | Magazzino cifrato (Supabase) delle credenziali. Mai nei repo. |
| **PIT** | La chiave API di una location GHL. |
